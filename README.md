# Reliable 4-Layer LLM Moderation API

This example demonstrates a reliable 4-layer architectural design for an LLM-based content moderation API. It showcases how input preprocessing, LLM interaction, output verification, and final decision-making layers work together to enhance the trustworthiness and consistency of moderation outcomes. The layered approach adds robustness against harmful or inappropriate content, even when the LLM might make an initial misjudgment.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
